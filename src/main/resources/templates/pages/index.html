Features

crusher is a tool that helps you track your bouldering progress, log your sessions, and crush your goals.

Track Sessions

Log your climbing sessions at different gyms and monitor your progress over time.

Rate Boulders

Rate and comment on boulders to help the community and refine your skills.

View Statistics

Analyze your climbing data with detailed statistics and insights.

See It In Action

The app is designed to be simple and easy to use, with a focus on providing a clean and intuitive user experience.

About this project

This application was built as a final project for the Software Engineering course at OTH Regensburg. It was developed by Samuel Kroiß, Hannes Weber, and Carl Czarnetzki.

Technologies used:

  • Spring Boot
  • Spring Security
  • Thymeleaf Templates
  • Tailwind CSS

Special thanks:

  • Neobrutalism Components for the design inspiration
  • Lucide Icons for the icons

crusher is open source. The complete source code can be found on GitHub:
